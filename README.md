# BlackJack
Tid: Januar-Februar i 2025

I det vi startet å jobbe på 1700 webprogrammering som inneholdt mye JavaScript så hadde jeg jo allerede lagd PebbleProjects repo hvor jeg lagde mange små prosjekter 
for å bare føle på JavaScript så nå ville jeg øve mer ved å lage noe større. På den tiden startet jeg nylig på spillet Balatro og var hooked på det, derfor var den
Balatro inspirert lookswise. Det var 2024 game of the year for a good reason. Jeg hadde lært meg mer om kortspill og til og med lært meg shuffles in real life too. 
Derfor ville jeg ta å lage en fungerende BlackJack med fungerende logikk der man kan hitte, så lenge man ikke har busta (over 21), og når man tar stay så hitter dealeren 
til han har 17 eller over. Den som buster taper, hvis ingen busta så vinner den med høyest sum av kort.
